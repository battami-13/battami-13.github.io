Password combinations (toy model)

Estimates how many different passwords are possible based on length and character set. Uses exponents to show why longer passwords are much harder to guess.

Note: This is a simplified model. Real password strength also depends on patterns and attacker knowledge.

If each character can be chosen from N symbols and the password has L characters, there are NL possible passwords. For example, 26 letters with length 4 gives 264 = 456,976 combinations.
